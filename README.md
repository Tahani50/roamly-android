# Roamly — Android

Native Android application for the Roamly travel planner.

Roamly helps users organize trips, daily itineraries, activities, expenses, packing lists, saved places and offline travel information.

Part of a three-platform study—the same application is built with SwiftUI, Flutter and Jetpack Compose using one shared backend.

## Status

🚧 In development — started September 2026

## Tech stack

Kotlin · Jetpack Compose · MVVM + Clean Architecture · Coroutines and Flow · Retrofit · Firebase Auth & FCM · Google Maps · Room
